Awd DriveRouter adalah aplikasi manajemen file dan perutean data lintas platform (Desktop & Android) yang memungkinkan transfer dan pengorganisasian file antar-layanan penyimpanan cloud dari satu dasbor tunggal.

### Fitur Utama
- **Cross-Platform Desktop & Android**: Berjalan secara efisien di Windows, macOS, Linux (berbasis Wails v2 + Go) dan perangkat mobile Android.
- **Perutean File Otomatis**: Fitur sinkronisasi dan aturan pengalihan file berkecepatan tinggi berbasis Go backend runtime.
- **Embedded Database**: Menyimpan konfigurasi akun, antrean transfer, dan log riwayat secara lokal menggunakan SQLite.
